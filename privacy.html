Privacy Policy

Last updated: August 20, 2026

This application ("Whoop MCP") is a personal integration that connects a single individual's Whoop account to their own Claude AI assistant, so that Claude can answer questions about that individual's recovery, sleep, workout, and strain data.

Data we access

With the account owner's explicit authorization via Whoop's OAuth flow, this application may access:

  • Basic profile information (name, email)
  • Recovery data (HRV, resting heart rate, recovery score)
  • Sleep data (duration, stages, sleep performance)
  • Workout data (strain, sport, duration, heart rate)
  • Physiological cycle data (daily strain, heart rate)
  • Body measurements (height, weight, max heart rate)

How data is used

Data is retrieved only in response to the account owner's own requests to their Claude assistant, and is used solely to answer questions about that owner's own health and fitness data. Data is not used for advertising, profiling, or any purpose beyond the owner's personal use.

Data storage and sharing

OAuth access and refresh tokens are stored on a private server controlled by the account owner. Data fetched from Whoop is passed through to the owner's own Claude conversation and is not persisted beyond what is needed to serve that conversation. This application does not sell, share, or provide Whoop data to any third party.

Single-user scope

This application is built for use by a single Whoop account holder (its developer) and is not intended for use by, or distribution to, the general public.

Revoking access

The account owner can revoke this application's access at any time from their Whoop account settings, which will immediately stop any further data access.

Contact

Questions about this policy can be directed to the application owner via their Whoop developer account.
